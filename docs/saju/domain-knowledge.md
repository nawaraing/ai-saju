# 명리학 지식 베이스 (Domain Knowledge)

> AI 사주 서비스의 해석 재료가 되는 명리학 지식을 정리한 문서.
> 계산 로직은 `saju-engine.md`, 해석 프롬프트는 `interpretation-prompt.md` 참고.
> 이 문서는 "무엇을 해석하는가(지식)"를 다루고, 프롬프트는 "어떻게 말하는가(지시)"를 다룬다.

---

## 0. 이 서비스가 채택한 해석 관점

> ⚠️ **먼저 정해야 할 것.** 명리학은 유파마다 해석이 갈린다(특히 용신).
> 서비스가 일관된 톤을 유지하려면 어떤 관점을 따를지 여기 명시한다.

- 채택 유파: (예: 자평명리 주류 / 조후 중시 / 현대적 순화 해석 등) — **결정 필요**
- 해석 태도: 결정론적 예언이 아니라, 자기 이해와 자기 점검을 돕는 참고 자료로 다룬다.
- 톤 원칙: 단정하지 않고 경향으로 말한다. 단점은 항상 보완책과 함께 제시한다.

## 1. 사주와 명리학의 구분

- **사주(四柱)** = 태어난 연·월·일·시를 60갑자로 바꾼 **여덟 글자(데이터)**. 같은 시각이면 누가 뽑든 동일한 고정값.
- **명리학(命理學)** = 그 여덟 글자를 해석하는 **학문(방법)**. 유파에 따라 관점이 다양.
- 비유: 사주 = 혈액 검사 수치(데이터), 명리학 = 그 수치를 읽는 의학(해석).
- 관련 용어:
  - **팔자(八字)**: 사주와 사실상 같은 말. "여덟 글자"에 방점.
  - **만세력(萬歲曆)**: 사주를 뽑을 때 참조하는 달력 데이터(절기 시각, 음양력 대응, 일진 등).
  - **역학(易學)**: 명리·주역·풍수·관상을 아우르는 상위 범주. 명리학은 그 한 갈래.

### 서비스 관점
- **계산(사주 뽑기)** = 코드 담당 → 정답이 하나, 환각 불가 영역.
- **해석(명리학)** = LLM 담당 → 관점이 개입, 이 문서와 프롬프트가 관장.

## 2. 음양(陰陽)

세상 모든 것을 짝을 이루는 두 성질로 나눈 가장 기본 개념. 우열이 아니라 대비.

| 양(陽) | 음(陰) |
|--------|--------|
| 밝음·낮·여름 | 어둠·밤·겨울 |
| 능동·확장·상승 | 수동·수렴·하강 |
| 남성적 기운(상징) | 여성적 기운(상징) |

### 2-1. 계절·시간의 음양 (흐름으로 이해)
음양은 세기보다 **흐름**으로 봐야 정확하다.

- **봄** = 음→양 상승 중. 약한 양(소양). 오행 목(木).
- **여름** = 양 극대. 오행 화(火).
- **가을** = 양→음 하강 중. 약한 음(소음). 오행 금(金).
- **겨울** = 음 극대. 오행 수(水).
- **환절기** = 중립. 오행 토(土).

→ 봄·가을을 "둘 다 중립"으로 묶으면 **틀림**. 방향이 반대(봄=상승 양, 가을=하강 음).
→ 진짜 중립에 가까운 것은 환절기의 **토(土)**.

### 2-2. 타고난 상태 vs 필요한 것 (조후) — 반드시 구분
- **타고난 상태**: 겨울 밤 = 음이 강함 / 여름 낮 = 양이 강함 (사실 판단)
- **필요한 것(조후 調候)**: 사주가 너무 차가우면(음 과다) 따뜻한 화(火)가 약(藥)으로 필요.
- 이 둘을 섞으면 "겨울 밤이니 양이 강하다" 같은 오류가 난다. 상태 판단과 처방을 단계로 나눌 것.

### 2-3. 성별과 음양 — 흔한 오해
- 상징 배속으로는 남=양, 여=음 (맞음).
- 그러나 **개인 사주의 음양 세기는 성별과 무관**, 여덟 글자로 결정됨.
  - 예: 겨울 밤생 남자 → 음 강함 / 여름 낮생 여자 → 양 강함.
- 성별이 실제로 쓰이는 곳은 딱 두 군데:
  1. **대운 방향 계산** (양남·음녀=순행, 음남·양녀=역행)
  2. **배우자 십신 해석** (남=재성을 아내, 여=관성을 남편 — 현대적 재해석 여지 있음)

### 2-4. 음양 편중별 성향과 보완 (해석 재료)

| 구분 | 양이 강함 | 음이 강함 |
|------|----------|----------|
| 방향 | 밖으로 확장 | 안으로 수렴 |
| 성향 | 외향·활동적 | 내향·신중 |
| 속도 | 빠름, 즉시 실행 | 느림, 숙고 |
| 강점 | 추진력·리더십·시작 | 집중력·인내·마무리 |
| 약점 | 성급·산만·용두사미 | 우유부단·소극·고립 |
| 감정 | 직접 표출 | 안으로 담음 |
| 보완재 | 차분함·마무리(음 보강) | 실행력·표현(양 보강) |

→ 좋은 사주는 "양이 강함/음이 강함"이 아니라 **치우침이 조절된 균형**. 해석은 늘 균형·보완으로 마무리.

### 서비스 관점
- 음/양 세기 판단은 **반드시 여덟 글자 기반**. 성별·단편 정보로 판단 금지.
- 프롬프트에서 "상태 판단(원국)"과 "처방(조후·용신)"을 별도 단계로 지시.
- 단정 금지, "~한 경향이 있어요" 톤. 단점은 보완책과 세트로 출력.

## 4. 상생·상극 (오행의 관계)

십신이 여기서 파생되므로 매우 중요.

### 상생(相生, 돕기) — 낳아주는 순환
목生화 → 화生토 → 토生금 → 금生수 → 수生목 → (반복)
- 목生화: 나무가 불을 지핌
- 화生토: 불이 타서 재(흙)가 됨
- 토生금: 흙 속에서 쇠가 남
- 금生수: 쇠 표면에 물이 맺힘
- 수生목: 물이 나무를 키움

### 상극(相剋, 누르기) — 억제하는 관계
목剋토 → 토剋수 → 수剋화 → 화剋금 → 금剋목 → (반복)
- 목剋토: 나무뿌리가 흙을 파고듦
- 토剋수: 흙이 물을 막음
- 수剋화: 물이 불을 끔
- 화剋금: 불이 쇠를 녹임
- 금剋목: 도끼가 나무를 벰

## 6. 일간(日干) — "나"의 기준점

- 여덟 글자 중 **태어난 날의 천간** 하나가 본인 자신(나)을 나타냄.
- 모든 해석은 "이 일간에서 봤을 때" 나머지 일곱 글자가 어떤 의미인가를 따지는 것.
- 십신·신강신약·용신 판단이 전부 일간을 기준으로 이뤄짐.

## 7. 십신(十神) — 해석 문장이 나오는 핵심

일간(나)을 기준으로, 다른 글자와의 오행 관계(상생상극) + 음양 동일/상이에 따라 열 가지 이름을 붙인다.

| 관계 | 십신 | 의미 |
|------|------|------|
| 나와 같은 오행 | 비견·겁재 | 형제·동료·경쟁자, 자아·주체성 |
| 내가 낳는 오행 | 식신·상관 | 표현·재능·활동·말 |
| 내가 누르는 오행 | 편재·정재 | 재물·성취·현실 감각 |
| 나를 누르는 오행 | 편관·정관 | 직장·명예·규율·압박 |
| 나를 낳아주는 오행 | 편인·정인 | 공부·문서·보살핌·수용 |

- "편/정"의 차이: 음양이 다르면 정(正, 안정적), 같으면 편(偏, 치우침·강렬).
- 실제 풀이 문장("당신은 재물 감각이 있고…")이 대부분 여기서 나옴.
- **AI 프롬프트에서 가장 공들일 부분.**

## 8. 신강·신약 (身强·身弱)

- 일간(나)이 나머지 글자들 사이에서 **힘이 센지(신강)·약한지(신약)** 판단.
- 나를 돕는 기운(비겁+인성) 많으면 신강 / 빼가고 누르는 기운(식상+재성+관성) 많으면 신약.
- **중요**: 같은 십신도 신강/신약에 따라 해석이 정반대.
  - 신강한 사람: 누르는 기운(관성)이 오히려 도움.
  - 신약한 사람: 같은 기운이 부담.

---

## 9. 용신(用神) — 균형을 맞추는 약

- 사주 전체에서 부족/과잉을 조절해줄 핵심 기운.
  - 신약 → 도와주는 오행이 용신.
  - 신강 → 빼주는 오행이 용신.
- "물 기운이 필요하다 / 파란색이 길하다 / 북쪽이 좋다" 같은 조언이 여기서 파생.
- ⚠️ 용신 잡는 법은 유파마다 갈리는 난이도 높은 영역. **서비스 초기엔 깊이 제한 권장.**
- (2-2의 조후도 용신 판단의 한 방식)

## 10. 대운(大運)·세운(歲運) — 시간의 흐름

- 지금까지(2~9)는 **타고난 것(원국)**. 여기에 시간을 얹는 것이 대운·세운.
- **대운**: 약 10년 단위로 바뀌는 큰 운의 흐름. 방향(순행/역행)은 성별+연간 음양으로 결정(2-3 참고).
- **세운**: 그 해(1년)의 운.
- 비유: 원국 = 지도, 대운 = 지금 걷는 길.
- "타고난 사주는 이런데, 지금 시기엔 이런 기운이 들어와서…" 식의 시기별 운세에 사용.

## 부록 A. 절기·음력·양력 (계산 전제 지식)

> 상세 구현은 `saju-engine.md`. 여기서는 개념만.

### 24절기 = 태양 기준 (음력 아님!)
- 절기는 태양 궤도(360°)를 15°씩 24등분한 것. **태양 기준이라 양력에 가까움.**
- 매년 양력 날짜 거의 고정 (춘분 3/20~21, 하지 6/21~22, 추분 9/22~23, 동지 12/21~22).
- 지구 공전 주기가 365.25일이라 하루 이틀 오차 → 정확한 계산엔 연도별 절기 시각 데이터 필요.

### 사주의 계절·연·월 기준
- **계절 시작**: 입춘(봄)·입하(여름)·입추(가을)·입동(겨울) — 대략 2/4, 5/5, 8/7, 11/7.
- **한 해 시작 = 입춘** (양력 1/1도, 음력 설날도 아님). 2월 초생은 연주가 갈릴 수 있음.
- **월(12달) 기준 = 12절**(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한).
- 24절기는 절(節, 월 시작) 12개 + 기(氣, 월 중간) 12개로 교대. 월주는 **절** 기준.

### 음력 처리
- **음력 ≠ 사주.** 음력은 달 기준, 사주는 절기(태양) 기준. "사주=음력"은 오해.
- 음력은 **사용자 입력 형식일 뿐**. 받는 즉시 양력 변환 후 절기 계산에 넘긴다.
- **윤달 필수 처리**: 음력은 몇 년에 한 번 같은 달을 반복(예: 윤4월). 입력 시 평달/윤달 플래그 반드시 확인.
- 변환은 공식이 아니라 **데이터 조회**. 한국은 한국천문연구원(KASI)이 공식 출처. 검증된 라이브러리/API 사용.

## 부록 B. 사용자 입력 플로우 (서비스 설계 연결)

1. 양력/음력 선택
2. (음력이면) 평달/윤달 선택
3. 생년월일 (YYYY-MM-DD)
4. 태어난 시각 (HH:mm, 모르면 시주 미확정 → 연·월·일 중심 보수적 풀이)
5. 성별 (대운 방향 계산에 필수)
6. (선택) 출생 시군구 — 진태양시(경도) 보정용
7. 보고 싶은 주제 (종합/연애/재물/직업/건강/한해운세/궁합)

→ 내부 처리: 음력이면 양력 변환 → 절기 따져 여덟 글자 계산 → 십신·신강신약·용신 산출 → LLM 해석.
